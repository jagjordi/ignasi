The **PhD Appendix** is the open-access research compendium underpinning my doctoral work. It contains the complete bar-level BPM dataset for all analysed recordings of Beethoven's five piano and cello sonatas, annotated portamento scores, and the full **Python and MATLAB** analysis code — covering all five visualisation types and the k-means clustering pipeline.

It is designed so that other researchers can reproduce every figure in the thesis and papers, and adapt the pipeline to their own performance corpora.

- **Repository:** [github.com/isolepinas/PhD-Appendix](https://github.com/isolepinas/PhD-Appendix)
- **Stack:** pandas, numpy, scipy, matplotlib, seaborn, scikit-learn; MATLAB
- **Contents:** BPM data, annotated scores, visualisation and clustering code
